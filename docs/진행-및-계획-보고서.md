## 1. 프론트엔드 / 백엔드 전체 구조

### [1] 프론트엔드 구조 (`subsync-extension` / `extension/`)
Chrome Extension (Manifest V3) 환경에서 동작하며, 유튜브 플레이어와 상호작용하여 자막 및 인터랙티브 UI를 제공합니다.

```text
extension/
├── manifest.json                  # 확장 프로그램 설정 (MAIN world inject, permissions 등)
├── popup.html                     # 확장 툴바 팝업 UI
├── assets/icons/                  # 아이콘 이미지
├── styles/                        # 기능별 세부 모듈화 CSS
│   ├── main.css                   # 전체 레이아웃 & 테마
│   ├── subtitle.css               # 실시간 이중자막 패널 스타일
│   ├── script.css                 # 전체 스크립트 뷰어 스타일
│   ├── interactive.css            # 단어 호버 툴팁 및 클릭 팝업 스타일
│   ├── tutor.css                  # Video Tutor 채팅창 & 선제 질문 스타일
│   └── modal.css                  # 로그인/회원가입 모달 스타일
└── src/
    ├── content_main.js            # Content Script 메인 진입점 (모듈 조립 & 라이프사이클)
    ├── background.js              # Service Worker
    ├── core/                      # 유튜브 플레이어 & 자막 코어 엔진
    │   ├── inject.js              # MAIN World 주입 (YouTube pot 우회, timedtext URL 가로채기)
    │   ├── captions.js            # 다국어 자막 파싱 및 시간축 병합
    │   └── player.js              # 유튜브 영상 제어 유틸 (seek, play, pause 등)
    ├── interactive/               # 단어 상호작용 엔진
    │   ├── tokenizer.js           # 영문 텍스트 단어 단위 파싱 및 <span> 토큰화
    │   ├── hover_tooltip.js       # Hover 시 간이 사전 툴팁 노출
    │   ├── click_popup.js         # Short Click 상세 사전 팝업 & 단어 저장
    │   └── interactive_text.js    # 텍스트 요소에 인터랙션 이벤트 바인딩
    ├── components/                # UI 컴포넌트 렌더러
    │   ├── layout.js              # 2열/오버레이 레이아웃 컨테이너
    │   ├── subtitle_view.js       # 실시간 동기화 이중자막 뷰
    │   ├── script_panel.js        # 전체 스크립트 패널 (토글 & 타임스탬프 점프)
    │   ├── tutor_chat.js          # Video Tutor AI 대화 UI & 피드백 버튼
    │   └── auth_modal.js          # 로그인/회원가입 팝업 모달
    └── services/                  # 백엔드 연동 API 클라이언트
        ├── api_client.js          # Fetch 래퍼 (토큰 주입, 에러 공통 처리)
        ├── auth_service.js        # 로그인/토큰 로컬 저장 관리
        ├── dict_service.js        # 사전 검색 (호버/상세)
        ├── tutor_service.js       # Video Tutor 질의/선제질문/피드백 API
        └── log_service.js         # 사용자 행동 및 성능 로그 전송 API
```

### [2] 백엔드 & 대시보드 구조 (`subsync-backend`)
FastAPI 기반 비동기 API 서버, Gemini AI 연동 엔진, Supabase PostgreSQL, Redis 캐시, Streamlit 데이터 분석 대시보드로 구성됩니다.

```text
subsync-backend/
├── app/
│   ├── main.py                    # FastAPI 진입점 (CORS, 라우터 마운트)
│   ├── core/                      # 시스템 공통 코어
│   │   ├── config.py              # 환경 변수 관리 (Pydantic Settings)
│   │   ├── security.py            # 비밀번호 해싱(bcrypt) 및 JWT 발급/검증
│   │   ├── database.py            # Supabase 클라이언트 연결
│   │   └── redis_client.py        # Redis 연결 풀 및 JSON 캐싱 유틸
│   ├── api/                       # API 라우트 계층
│   │   ├── deps.py                # JWT 기반 인증 의존성 주입 (get_current_user)
│   │   └── v1/
│   │       ├── auth.py            # /api/v1/auth (회원가입, 로그인, 내 정보)
│   │       ├── dictionary.py      # /api/v1/dict (호버 간이사전, 상세 사전)
│   │       ├── words.py           # /api/v1/words (단어 저장, 단어장 조회)
│   │       ├── tutor.py           # /api/v1/tutor (AI 튜터 질의, 선제질문, 피드백)
│   │       └── logs.py            # /api/v1/logs (사용자 행동 & 시스템 로그 수집)
│   ├── schemas/                   # Pydantic DTO (요청/응답 모델)
│   │   ├── auth.py
│   │   ├── dictionary.py
│   │   ├── words.py
│   │   ├── tutor.py
│   │   └── logs.py
│   ├── services/                  # 핵심 비즈니스 로직
│   │   ├── auth_service.py        # 회원 인증 및 토큰 발급 로직
│   │   ├── dict_service.py        # 3단계 사전 검색 (Redis 캐시 -> 로컬 사전 -> 외부 API)
│   │   ├── word_service.py        # 나만의 단어장 CRUD
│   │   └── log_service.py         # Supabase 저장 + Redis 실시간 스트림 적재
│   ├── ai/                        # AI & LLM 특화 모듈
│   │   ├── gemini_client.py       # Google Gemini SDK 연동
│   │   ├── prompts.py             # Video Tutor & 선제 질문 프롬프트
│   │   ├── context_builder.py     # 영상 타임스탬프 문맥 자막 결합기
│   │   └── tutor_service.py       # AI 튜터 응답 생성 및 피드백 처리
│   └── data/
│       └── base_dictionary.json   # 고빈도 영단어 오프라인 사전 데이터
├── dashboard/                     # Streamlit 분석 대시보드
│   ├── app.py                     # 대시보드 메인 진입점
│   ├── components/                # 대시보드 UI 컴포넌트
│   │   ├── kpi_metrics.py         # 핵심 운영 지표 (DAU, 클릭수, 만족도)
│   │   ├── realtime_logs.py       # 실시간 사용자 행동 로그 테이블
│   │   └── feedback_view.py       # AI 피드백 통계 차트
│   └── analytics/                 # 데이터 분석 & 알고리즘 모듈
│       ├── data_loader.py         # 로그 데이터 수집 및 정제
│       ├── user_patterns.py       # 최다 클릭/취약 단어 분석
│       └── ai_quality_eval.py     # 응답 속도/길이와 만족도 상관분석
├── docs/                          # 프로젝트 설계 및 명세 문서
│   ├── api_spec.md                # REST API 상세 규격서
│   ├── db_schema.sql              # Supabase PostgreSQL DDL
│   ├── architecture.md            # 전체 아키텍처 및 데이터 흐름도
│   └── subsync-architecture-guide.md # 2-Repo 분리 배경 및 팀 R&R 가이드
├── tests/                         # 단위 및 통합 테스트
│   ├── test_auth.py
│   ├── test_dict.py
│   └── test_tutor.py
├── requirements.txt               # 백엔드 의존성 패키지 목록
├── Dockerfile                     # 컨테이너 빌드 파일
└── .env.example                   # 환경 설정 템플릿
```

### 3) 백엔드 (`app/` & `dashboard/`) 구현
