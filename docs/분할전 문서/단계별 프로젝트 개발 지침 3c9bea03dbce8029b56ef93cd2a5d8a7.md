# 단계별 프로젝트 개발 지침

## 0. 프로젝트 최종 목표

이 프로젝트는 YouTube에서 제공되는 영어/한국어 자막을 이용해 영어를 학습하는 Chrome Extension이다.

초기에는 자막 기반 학습 도구로 시작하고, 이후 사용자의 학습 데이터를 지속적으로 축적한 뒤, 최종적으로는 그 데이터를 기반으로 AI와 개인화된 영어 대화를 할 수 있는 학습 도구로 발전시킨다.

최종 구조는 다음과 같다.

Chrome Extension
→ FastAPI Backend
→ RDS
→ ElastiCache
→ LLM
→ 개인화 영어 학습

중요:

- 개발은 반드시 단계별로 진행한다.
- 현재 단계에서 요구하지 않은 다음 단계 기능은 미리 구현하지 않는다.
- 단, 이후 확장이 가능하도록 코드 구조는 분리한다.
- 각 단계는 구현 후 반드시 테스트하고, 테스트가 통과한 뒤 다음 단계로 이동한다.

# 1단계 — YouTube 영/한 자막 표시

## 목표

현재 보고 있는 YouTube 영상의 영어 자막과 한국어 자막을 Chrome Extension UI에서 표시한다.

## 구현 범위

- Chrome Extension Manifest V3
- HTML / CSS / JavaScript
- 현재 YouTube 영상 식별
- 영어 자막 표시
- 한국어 자막 표시
- 문장별 timestamp 관리

## 자막 데이터 기본 구조

{
"video_id": "...",
"timestamp": 123.4,
"english": "...",
"korean": "..."
}

## 아직 구현하지 말 것

- FastAPI
- DB
- 로그인
- Redis
- AI
- AWS 배포

## 완료 조건

- 개발자 모드에서 확장 프로그램 로드 가능
- YouTube 영상에서 영/한 자막이 정상적으로 표시됨
- 영상 재생 위치와 자막 timestamp가 맞음

# 2단계 — 자막 기반 학습 UI

## 목표

사용자가 자막을 이용해 실제 영어 학습을 할 수 있는 최소 기능을 만든다.

## 구현 범위

- 영어만 보기
- 영어 + 한국어 같이 보기
- 자막 문장 클릭 시 해당 영상 위치로 이동
- 문장 저장 버튼
- 단어/표현 저장 버튼
- 현재 학습 중인 문장 표시

## 아직 구현하지 말 것

- FastAPI
- DB
- 로그인
- AI
- AWS

## 완료 조건

- 사용자가 영상 시청 중 자막을 보며 학습 가능
- 저장 버튼 동작 확인
- 문장 클릭 시 정확한 영상 위치로 이동

# 3단계 — Chrome Extension과 FastAPI 연결

"saved_at": "..."

- FastAPI 응답을 Extension에서 확인

- subtitle_id

- FastAPI와 RDS 연결
- 데이터 생성
- 조회
- 수정
- 삭제
- 학습 기록 저장

## 아직 구현하지 말 것

# 5단계 — 학습 데이터 구조 확장

## 목표

향후 AI 학습에 사용할 수 있도록 사용자 학습 행동 데이터를 축적한다.

## 저장할 데이터 예시

- 저장한 문장
- 저장한 단어
- 저장한 표현
- 모르는 문장
- 다시 본 문장
- 이해 완료 여부
- 복습 횟수
- 난이도
- 영상별 학습 기록
- 날짜별 학습 기록

## 목적

향후 AI가 다음 정보를 파악할 수 있어야 한다.

- 사용자가 자주 모르는 단어
- 반복해서 저장하는 표현
- 어려워하는 문법
- 최근 학습 내용
- 복습이 필요한 문장

## 완료 조건

- 주요 학습 행동이 DB에 기록됨
- 사용자별 학습 이력을 조회할 수 있음

# 6단계 — 사용자 인증

## 목표

여러 사용자가 서비스를 사용해도 학습 데이터가 서로 섞이지 않도록 한다.

## 구현 범위

- 회원가입
- 로그인
- 인증 토큰
- 사용자별 데이터 분리
- 인증이 필요한 API

## 테스트

- A 사용자는 A 데이터만 조회
- B 사용자는 B 데이터만 조회
- 인증 없이 보호 API 접근 시 실패

## 아직 구현하지 말 것

- AI
- 운영 배포 최적화

# 7단계 — ElastiCache 도입

## 목표

반복 요청과 임시 데이터를 빠르게 처리한다.

## 기술

AWS ElastiCache

- Redis 또는 Valkey

## 사용 후보

- 자주 조회하는 자막
- 영상 정보
- 반복 API 결과
- 세션
- 임시 상태
- 캐시

## 중요

Redis를 먼저 넣지 않는다.
DB 기능이 안정된 뒤 도입한다.

## 완료 조건

- 캐시가 없어도 서비스가 정상 동작
- 캐시 사용 시 반복 조회가 정상적으로 처리됨

# 8단계 — 첫 AI 기능

## 목표

저장한 자막 문장을 기반으로 AI가 학습을 도와준다.

## 구현 기능 예시

사용자가 저장한 문장에 대해:

- 문장 해석
- 문법 설명
- 주요 표현 설명
- 유사 예문 생성
- 간단한 퀴즈 생성

## 데이터 흐름

Chrome Extension
→ FastAPI
→ 학습 데이터 조회
→ LLM 호출
→ AI 응답
→ Extension 표시

## 완료 조건

- 사용자가 저장한 실제 자막을 기준으로 AI 응답 생성
- 임의 문장이 아니라 DB의 학습 기록과 연결됨

# 9단계 — 개인화 AI 영어 대화

## 목표

사용자가 지금까지 학습한 데이터를 기반으로 AI와 영어 대화를 한다.

## 예시

사용자:
"오늘 내가 배운 표현으로 대화 연습하자."

AI가 참고할 데이터:

- 최근 저장한 자막
- 자주 모르는 표현
- 어려워했던 문장
- 복습이 필요한 문장
- 최근 본 영상
- 사용자의 학습 기록

## 핵심

AI는 일반 챗봇이 아니라 사용자의 실제 학습 데이터를 참고해야 한다.

## 완료 조건

- AI 대화가 사용자의 학습 이력을 실제로 활용함
- 사용자별 개인화가 구분됨

- 사용자의 DB 기록을 기반으로 분석 결과 생성

# AI 개발 작업 규칙

AI는 항상 아래 규칙을 따라야 한다.

1. 현재 요청받은 단계만 구현한다.
2. 다음 단계 기능을 임의로 미리 구현하지 않는다.
3. 코드를 작성하기 전에 현재 단계의 목표를 먼저 확인한다.
4. 기존 동작을 깨지 않도록 수정한다.
5. 각 단계마다 테스트 방법을 제공한다.
6. 테스트 예상 결과를 명확히 적는다.
7. 테스트가 실패하면 다음 단계로 넘어가지 않는다.
8. Secret, API Key, DB Password를 Chrome Extension 코드에 넣지 않는다.
9. Backend와 Frontend 책임을 명확히 분리한다.
10. 향후 확장은 고려하되 현재 구현을 과도하게 복잡하게 만들지 않는다.
11. 한 단계가 끝날 때마다 변경된 파일 목록을 보여준다.
12. 각 단계가 끝날 때 다음 단계로 넘어가기 전에 현재 구현 상태를 요약한다.

- 이해 완료 여부
- 복습 횟수
- 난이도
- 영상별 학습 기록
- 날짜별 학습 기록

## 목적

향후 AI가 다음 정보를 파악할 수 있어야 한다.

- 사용자가 자주 모르는 단어
- 반복해서 저장하는 표현
- 어려워하는 문법
- 최근 학습 내용
- 복습이 필요한 문장

## 완료 조건

- 주요 학습 행동이 DB에 기록됨
- 사용자별 학습 이력을 조회할 수 있음

# 6단계 — 사용자 인증

## 목표

여러 사용자가 서비스를 사용해도 학습 데이터가 서로 섞이지 않도록 한다.

## 구현 범위

- 회원가입
- 로그인
- 인증 토큰
- 사용자별 데이터 분리
- 인증이 필요한 API

## 테스트

- A 사용자는 A 데이터만 조회
- B 사용자는 B 데이터만 조회
- 인증 없이 보호 API 접근 시 실패

## 아직 구현하지 말 것

- AI
- 운영 배포 최적화

# 7단계 — ElastiCache 도입

## 목표

반복 요청과 임시 데이터를 빠르게 처리한다.

## 기술

AWS ElastiCache

- Redis 또는 Valkey

## 사용 후보

- 자주 조회하는 자막
- 영상 정보
- 반복 API 결과
- 세션
- 임시 상태
- 캐시

## 중요

Redis를 먼저 넣지 않는다.

## 완료 조건

- 캐시가 없어도 서비스가 정상 동작
- 캐시 사용 시 반복 조회가 정상적으로 처리됨

# 9단계 — 개인화 AI 영어 대화

## 목표

사용자가 지금까지 학습한 데이터를 기반으로 AI와 영어 대화를 한다.

## 예시

"오늘 내가 배운 표현으로 대화 연습하자."

AI가 참고할 데이터:

- 최근 저장한 자막
- 자주 모르는 표현
- 어려워했던 문장
- 복습이 필요한 문장

# AI 개발 작업 규칙

AI는 항상 아래 규칙을 따라야 한다.

1. 현재 요청받은 단계만 구현한다.
2. 다음 단계 기능을 임의로 미리 구현하지 않는다.
3. 코드를 작성하기 전에 현재 단계의 목표를 먼저 확인한다.
4. 기존 동작을 깨지 않도록 수정한다.
5. 각 단계마다 테스트 방법을 제공한다.
6. 테스트 예상 결과를 명확히 적는다.
7. 테스트가 실패하면 다음 단계로 넘어가지 않는다.
8. Secret, API Key, DB Password를 Chrome Extension 코드에 넣지 않는다.
9. Backend와 Frontend 책임을 명확히 분리한다.
10. 향후 확장은 고려하되 현재 구현을 과도하게 복잡하게 만들지 않는다.
11. 한 단계가 끝날 때마다 변경된 파일 목록을 보여준다.
12. 각 단계가 끝날 때 다음 단계로 넘어가기 전에 현재 구현 상태를 요약한다.
