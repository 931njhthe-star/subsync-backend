# 기획

• 서버: `venv + FastAPI`
• SQL DB: **RDS(PostgreSQL/MySQL)** 사용.
• 캐시 DB: **ElastiCache(Redis/Valkey)** 사용.
• 운영환경: FastAPI 앱을 **Docker 컨테이너**로 만들고 AWS에 배포하면 됨.
• 배포 대상은 EC2도 가능하지만 **ECS/Fargate**가 컨테이너 운영에는 더 편함.
• 구조는 대략 `Client → ALB → ECS(FastAPI) → RDS + ElastiCache`.
• 비밀번호/API Key는 코드에 넣지 말고 **Secrets Manager / Parameter Store** 사용 권장.
• 즉, 큰 수정점은 **“운영환경에서는 venv를 직접 관리하기보다 Docker가 그 역할을 대신한다”** 정도야.
