## 1단계 — YouTube 영/한 자막 표시

### 목표 (docs 기준)
- MV3 확장에서 현재 YouTube 영상의 영어 자막 + 한국어 자막 표시
- 문장별 timestamp 관리, 영상 재생 위치와 자막 동기화
- 하지 말 것: FastAPI/DB/로그인/Redis/AI/배포, 그리고 클릭-이동·저장 버튼(2단계)

### 한 일
1. 자막 패널 UI와 재생 위치 하이라이트 구현.
2. 콘텐츠 스크립트 스코프 충돌 버그 수정.
3. 자막 본문 로딩 실패 원인 진단 후 수집 방식 재설계.

### 주요 이슈와 해결

#### (1) 패널이 안 뜸 — `const YLTK` 중복 선언
- 원인: `captions.js`와 `content.js`가 같은 콘텐츠 스크립트 스코프를 공유하는데
  둘 다 최상위에서 `const YLTK`를 선언 → 두 번째 파일이 "이미 선언된 식별자"
  오류로 실행되지 않아 패널이 생성되지 않음.
- 해결: 각 파일을 IIFE `(function(){ ... })()`로 감싸 지역 스코프화.

#### (2) 자막 본문이 빈 응답 — YouTube pot 정책
- 실측(브라우저에서 확장 로직 재현):
  - 자막 트랙 목록은 정상 파싱(영어·한국어 포함 50개).
  - 자막 본문 API `/api/timedtext` 요청이 **HTTP 200 + 본문 0바이트**.
  - 클래식 URL, InnerTube `get_transcript`(400 Precondition failed) 모두 실패.
- 원인: YouTube가 자막 본문 URL에 `pot`(proof-of-origin token)을 요구하도록 변경.
  확장이 직접 만든 URL엔 pot이 없어 빈 응답만 받음.
- 해결: **플레이어가 실제로 보내는 자막 요청을 가로채는 방식**으로 변경.
  - MAIN 월드에 `inject.js`를 주입해 `fetch`/`XHR`을 후킹, 플레이어의 timedtext
    요청 URL(유효 pot 포함)을 가로챔.
  - 플레이어가 자막을 로드하도록 유도(자동 CC on)해 사용자가 CC를 켜지 않아도 동작.
  - 가로챈 URL의 `lang`/`tlang` 파라미터만 바꿔 영어/한국어 자막을 각각 받아 병합
    (lang/tlang/fmt는 서명 대상 파라미터가 아니라 교체 가능).

### 데이터 구조
```
{ video_id, timestamp, english, korean }
```

### 변경/추가 파일
- `extension/manifest.json` — 아이콘 참조 제거, `inject.js`를 `world:"MAIN"`,
  `document_start`로 등록
- `extension/src/inject.js` (신규, MAIN 월드) — timedtext 가로채기 + 트랙/URL 전달 +
  자막 자동 로드 유도 + SPA 내비게이션 리셋
- `extension/src/captions.js` — 가로챈 URL 기반 en/ko 자막 빌드(`buildSubtitlesFromUrl`)
- `extension/src/content.js` — postMessage 수신, 자막 렌더링, 재생 동기화, 상태 안내
- `extension/styles/panel.css` — 자막 패널 스타일
- `extension/popup.html`, `styles/popup.css`, `src/popup.js`, `src/background.js`,
  `src/storage.js` — 기본 스캐폴딩

### 실행/테스트 방법
1. `chrome://extensions` → 개발자 모드 ON → "압축해제된 확장 프로그램 로드" → `extension/`
2. 자막 있는 YouTube 영상으로 이동 후 새로고침
3. 우측 패널에 영/한 자막이 표시되고, 재생 위치에 맞춰 현재 문장이 강조되는지 확인

디버깅(콘솔 F12):
- `[YLTK/inject] timedtext URL 가로챔` 로그 → 가로채기 성공 여부
- 로그가 없으면 영상 하단 CC 버튼을 직접 켜서 플레이어가 자막을 로드하게 함
- `[YLTK] 자막 로드 실패` 에러 메시지 확인

### 완료 조건 점검
- [x] 개발자 모드 로드 가능
- [ ] 영/한 자막 표시 (사용자 실제 브라우저에서 최종 확인 필요)
- [ ] 재생 위치와 timestamp 동기화 (사용자 확인 필요)

### 한계 / 남은 확인
- 테스트용 브라우저(비로그인)는 YouTube가 자막을 차단해 최종 렌더링을 직접 검증하지 못함.
  로그인된 실제 Chrome에서 동작 확인 필요.
- 한국어 네이티브 트랙이 없으면 기계 번역(tlang=ko)으로 대체 → 품질은 표시 목적 수준.

## 1단계 보강 — 배울/아는 언어 선택 (UX)

### 요청
- "배울 자막"(위 줄)과 "아는 언어"(아래 줄)를 사용자가 선택 가능하게.

### 추가한 기능
- 패널 상단에 드롭다운 2개: **배울 언어**(위), **아는 언어**(아래).
- 선택지 = 이 영상의 원어 자막 트랙 + 주요 언어(COMMON_LANGS) 합집합.
  원어 캡션이 아닌 항목은 라벨에 `(자동번역)` 표시.
- 선택값을 `chrome.storage.local`에 저장 → 다음 영상/세션에도 유지.
- **아는 언어 "표시 안 함"** 옵션 → 아래 줄 숨기고 배울 언어만 보기.
- 선택 변경 시 새로고침 없이 즉시 자막 재로드(재빌드).
- 기본값: 배울 언어=영어, 아는 언어=한국어.

### 구현 상세
- 자막 데이터 구조를 언어 중립적으로 변경: `{ video_id, timestamp, learn, known }`.
- `captions.js`:
  - `resolveNativeLang(nativeLangs, lang)` — 선택 언어의 네이티브 트랙 코드 해석
    (정확 일치 → 기본 언어코드 일치).
  - `buildSubtitlesFromUrl(videoId, url, { tracks, learnLang, knownLang })` —
    네이티브면 `lang` 교체, 아니면 source 트랙 + `tlang`(자동 번역)으로 각각 로드 후 병합.
- `content.js`: 언어 드롭다운 UI, 옵션 구성(`Intl.DisplayNames`로 한국어 언어명),
  설정 저장/복원, `videoId+언어조합` 키 기반 재빌드 가드.
- `panel.css`: `.yltk-controls`, `.yltk-select`, `.yltk-field` 및
  `.yltk-en/.yltk-ko` → `.yltk-learn/.yltk-known` 리네이밍.

- `extension/src/captions.js`
- `extension/src/content.js`
- `extension/styles/panel.css`

## 1단계 보강 — CC 버튼 없이 자막 자동 수집

### 요청
- 영상 하단 CC 버튼을 직접 켜지 않아도 확장이 자막을 가져오게.

### 방식
- `inject.js`가 플레이어 API로 자막을 잠깐 자동 활성화해 timedtext 요청을 유발하고,
  그 요청 URL을 가로챈 뒤 **원래 CC 상태로 되돌린다**(영상 위 오버레이가 남지 않음).
  - `getPlayer()`: `#movie_player`의 `getOption/setOption/loadModule` 준비 여부 확인.
  - `tryEnableCaptions()`: 원래 자막 상태 저장 → `loadModule('captions')` →
    `getOption('captions','tracklist')`에서 영어(우선) 트랙 선택 →
    `setOption('captions','track', …)` + `setOption('captions','reload', true)`.
  - `restoreCaptionState()`: 가로챈 뒤 원래 켜져 있었으면 유지, 꺼져 있었으면 다시 끔.
  - 폴링 주기 0.5초, 최대 ~30초(광고/지연 로딩 대응). SPA 이동 시 상태 초기화.

### 검증 메모
- 테스트용(비로그인) 브라우저에서는 YouTube가 해당 세션 자막을 "사용 불가"
  (`is_servable:false`)로 막아, 트랙을 켜도 요청이 발생하지 않아 캡처를 직접 확인 못함.
- 다만 플레이어 캡션 API(`hasPlayerApi:true`, tracklist 접근)는 정상 동작 확인.
  로그인된 실제 Chrome(자막 servable)에서는 자동 활성화로 요청이 유발되어야 함.
- 자동 활성화가 실패하면 content.js가 "CC를 켜 주세요" 안내를 표시(폴백).

### 변경 파일
- `extension/src/inject.js`

## 1단계 보강 — 전체 언어 선택 지원

### 요청
- 언어 선택지를 (하드코딩 16개가 아니라) 전체로 확장.

### 방식
- `inject.js`가 `playerCaptionsTracklistRenderer.translationLanguages`(자동번역 대상
  전체 언어, 실측 156개)를 `TRACKS` 메시지에 함께 전달.
- `content.js`가 드롭다운을 (원어 트랙 + 전체 번역 언어)로 구성. 번역 목록을 못 받은
  경우에만 기존 COMMON_LANGS로 폴백.
- 라벨은 `Intl.DisplayNames(['ko'])` 우선, 해석 실패 시 YouTube 제공 언어명으로 대체.
  원어가 아닌 언어는 `(자동번역)` 표시.

### 변경 파일
- `extension/src/inject.js`, `extension/src/content.js`
