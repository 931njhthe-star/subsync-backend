# GitHub Desktop 사용 가이드 (Git 처음 배우는 팀원용)

Git을 명령어(CLI)로 배우면 진입장벽이 높습니다. GitHub Desktop은 클릭 몇 번으로 같은 작업을 할 수 있게 해주는 GUI 프로그램입니다. 이 가이드는 GitHub Desktop 화면을 기준으로 작성했습니다.

---

## 0. 설치 및 로그인

1. https://desktop.github.com 에서 다운로드 후 설치
2. 실행 후 `File > Options > Accounts` (Mac은 `GitHub Desktop > Preferences > Accounts`)에서 GitHub 계정으로 로그인
3. 로그인하면 회사/팀 저장소에 접근할 수 있는 권한이 연결됩니다

---

## 1. 저장소 클론(Clone)하기

“클론”은 GitHub에 있는 원격 저장소를 내 컴퓨터로 복사해오는 작업입니다.

1. 상단 메뉴에서 `File > Clone Repository` 클릭
2. 뜨는 창에서 3가지 탭 확인
    - **GitHub.com**: 내 계정/조직에 있는 저장소 목록에서 선택 (가장 쉬움)
    - **URL**: 저장소 주소(`https://github.com/조직명/저장소명.git`)를 직접 붙여넣기
    - **Local**: 이미 로컬에 있는 폴더를 등록
3. `Local Path`에서 저장소를 저장할 내 컴퓨터 폴더 위치 지정
4. `Clone` 버튼 클릭 → 다운로드 완료되면 자동으로 해당 저장소가 열림

> 팀 저장소를 처음 받을 때는 GitHub.com 탭에서 찾는 게 제일 안전합니다. 오타로 잘못된 URL을 치는 실수를 줄여줍니다.
>

## 2. 화면 구성 한눈에 보기

GitHub Desktop을 열면 화면이 크게 3영역으로 나뉩니다.

| 위치 | 이름 | 역할 |
| --- | --- | --- |
| 왼쪽 상단 | Current Repository | 지금 작업 중인 저장소 선택 |
| 왼쪽 상단 (그 옆) | Current Branch | 지금 작업 중인 브랜치 선택/생성 |
| 왼쪽 패널 | Changes / History 탭 | Changes: 지금까지 수정한 파일 목록, History: 과거 커밋 기록 |
| 오른쪽 패널 | Diff 뷰 | 선택한 파일에서 무엇이 바뀌었는지 (초록=추가, 빨강=삭제) |
| 오른쪽 하단 | 커밋 메시지 입력창 | 변경사항을 커밋할 때 설명 작성 |

## 3. 작업 흐름 (가장 중요)

### ① 코드 수정

평소처럼 VS Code 등 에디터에서 파일을 수정합니다.

### ② 변경사항 확인 (Changes 탭)

- GitHub Desktop으로 돌아오면 `Changes` 탭에 수정된 파일 목록이 자동으로 표시됩니다
- 파일을 클릭하면 오른쪽에 무엇이 바뀌었는지(diff) 보입니다
- 체크박스로 이번 커밋에 포함할 파일만 선택할 수 있습니다 (일부만 커밋 가능)

### ③ 커밋(Commit)

- 화면 왼쪽 하단 입력창에 커밋 메시지 작성
    - **Summary**: 한 줄 요약 (예: “로그인 화면 버튼 색상 수정”)
    - **Description**: 필요하면 상세 설명 추가
- `Commit to [브랜치명]` 버튼 클릭
- 커밋은 “내 컴퓨터에만 저장된 변경 기록”입니다. 아직 GitHub 서버에는 올라가지 않은 상태입니다

### ④ 푸시(Push)

- 커밋 후 화면 상단에 `Push origin` 버튼이 나타납니다
- 클릭하면 내 커밋들이 GitHub 서버(원격 저장소)로 업로드됩니다
- 이 순간부터 팀원들이 내 변경사항을 볼 수 있습니다

### ⑤ 풀(Pull / Fetch)

- 팀원이 먼저 푸시한 변경사항을 내려받는 작업
- 상단 버튼이 `Fetch origin`으로 보이면 클릭 → 새 커밋이 있으면 `Pull origin`으로 바뀜 → 다시 클릭
- **작업 시작 전에는 항상 Pull부터 하는 습관**을 들이면 충돌을 많이 줄일 수 있습니다

## 4. 브랜치(Branch) 사용하기

브랜치는 “원본을 건드리지 않고 따로 작업하는 공간”입니다. 팀 작업에서는 보통 `main`(또는 `master`) 브랜치에 바로 작업하지 않고, 새 브랜치를 만들어 작업합니다.

1. 왼쪽 상단 `Current Branch` 클릭
2. `New Branch` 클릭
3. 브랜치 이름 입력 (예: `feature/login-ui`, `fix/button-color`)
4. `Create Branch` 클릭 → 자동으로 그 브랜치로 전환됨
5. 이 상태에서 수정 → 커밋 → 푸시를 진행하면 `main`은 그대로 두고 새 브랜치에만 기록됩니다
6. 브랜치를 바꿀 때는 다시 `Current Branch` 드롭다운에서 원하는 브랜치 선택
